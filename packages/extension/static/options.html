Commit Four

Play Connect 4 against an AI on your own GitHub contribution graph. Each piece is a few backdated, empty commits in a dedicated board repo: 4 for yours, 2 for the AI's.

Board repository

Enter your GitHub username.

Enter the name of your board repo (created from the template, or with commit-four init).

Enter the default branch (usually main).

How moves get written

Use the port shown by commit-four serve.

Paste the pairing token printed by commit-four serve.

Paste a fine-grained token (it starts with github_pat_).

Create one: Repository access → only your board repo; Permissions → Contents: Read and write; short expiry. It is stored only in this browser and only sent to api.github.com.

Good to know

  • Boards are drawn in past "season" years (2016, then 2015, …), so your real recent activity keeps its look. Open that year on your profile to play.
  • If your profile activity is private, only you can see the board.
  • Commit Four only writes to repos containing its .commit-four-board file, never force-pushes, and keeps volumes tiny (about 130 commits per game).
  • Unofficial project; GitHub's abuse detection could still flag unusual activity. Use at your own risk.
